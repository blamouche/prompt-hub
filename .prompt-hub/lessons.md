# Lessons

## Always create the task file BEFORE acting

**Rule:** For every task (even simple ones like adding an image to a README), create `.prompt-hub/todo/todo-<YYYYMMDD-HHmmss>-<slug>.md` before executing any changes.

**Why:** The user corrected this on 2026-03-13 — the task file was created after the work was done, which violates the CLAUDE.md mandate.

**How to apply:** First action in any task = write the todo file. No exceptions, regardless of task size.
